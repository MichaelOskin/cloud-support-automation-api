# Демонстрация сценариев использования Cloud Support Automation API

Эта директория содержит набор демонстраций для быстрого ознакомления с возможностями API


## 1. Подготовка и запуск демонстрационной среды

Для запуска демонстраций необходимо, чтобы ваше основное приложение `cloud-support-automation-api` было запущено.
Вы можете запустить его, используя `docker-compose` из корневой директории проекта или локально через `gradle bootRun`.

**Пример запуска основного приложения (через Docker Compose):**
```bash
cd .. # Перейти в корневую директорию проекта
docker compose up -d app
```

Затем вернитесь в директорию `usecases/`:
```bash
cd usecases
```

**Запуск демонстрационных сервисов:**
Этот `docker-compose.yml` запустит сервисы к которым будем подключаться.
```bash
docker-compose up -d --build
```
Убедитесь, что SSH-сервер (с Nginx) запустился:
```bash
docker-compose ps
```
Вы должны увидеть `usecases_test_ssh_server` со статусом `Up`.

## 2. Запуск демонстраций

После того как основное приложение и демонстрационные сервисы запущены, вы можете выполнять скрипты из директории `scripts/`.

**Пример запуска скрипта (успешное выполнение SSH-команды):**
```bash
# if needed
chmod +x ./scripts/run_alldemos.sh
./scripts/run_alldemos.sh
```

**Описание сценариев:**
- `demo_ssh_success.sh`: Демонстрирует успешное выполнение SSH-команды и получение результата.
- `demo_ssh_auth_fail.sh`: Демонстрирует обработку ошибки аутентификации при выполнении SSH-команды.
- `demo_ssh_command_fail.sh`: Демонстрирует обработку ошибки выполнения самой команды на удаленном сервере.
- `demo_user_task_association.sh`: Демонстрирует создание пользователя и привязку задачи к нему.
- `demo_nginx_status.sh`: Демонстрирует SSH-запрос для проверки статуса Nginx на тестовой VM.
- `demo_aws_ec2_with_ssh.sh`: Демонстрирует создание EC2-инстанса в AWS и выполнение команды на нем через SSH по ключу.
